## 🏗️ Local Environment Setup & API Configuration

To deploy this Android architecture on your local workspace:

1. Clone or Fork this repository directly into your **Android Studio** workspace.
2. Create an authorized endpoint registry profile at [OpenWeatherMap](https://openweathermap.org).
3. Generate your dedicated API authentication credential string.
4. Open the `LocationCord.java` system file and register your access key in the defined static string parameter:

```java
public final static String API_KEY = "81a26c8f0de407b94623e9f43e825679";
```
